# MECA 사장님 모바일 웹 푸시 알림 (무료 파일럿)

## 목표 및 한계

- **기존 관리자 화면 브라우저 알림:** 대시보드 탭을 열어둔 동안만 동작.
- **모바일 웹 푸시:** 사장님이 한 번 기기에서 권한을 허용하고 구독하면 탭을 닫아도 Push API/서비스 워커를 통해 예약 접수·변경·취소 알림을 전송 시도. Android Chrome 등의 지원 브라우저에 적합.
- **iPhone/iPad:** 지원 OS의 Safari에서 ‘홈 화면에 추가’로 MECA 웹앱을 설치하고, 홈 화면 아이콘으로 열어 알림 권한을 허용해야 함. 일반 Safari 탭이나 인앱 브라우저에서 알림이 되지 않을 수 있음.
- **전달 보장 불가:** 기기 알림 권한, 네트워크 연결, 배터리/절전 정책, 푸시 게이트웨이 장애에 따라 지연/누락 가능. 수신은 사장님 본인의 기기로 실제 테스트 필요.
- **무료 발송 구조:** Resend/문자/Kakao 발송업체는 사용하지 않으며 공개 브라우저 Push API를 사용. 서버 사용량과 호스팅 자원은 별도 과금·한도 가능.
- **개인정보:** 푸시 내용에 고객 이름·번호·정비 내역·예약 관리 비밀 토큰 없음. 푸시 구독 endpoint/key는 DB에 보관되고 정비소 소유주만 조회 가능.
- 매장 가입/활성화와 무관하게 기존 고객 알림톡은 계속 비활성.

## 사용

1. 사장님 계정으로 MECA **대시보드 → 매장 설정** 접속.
2. **휴대전화 예약 푸시 알림**에서 **이 휴대전화에서 알림 받기** 선택 후 브라우저 알림 권한 허용.
3. 테스트 고객 예약을 신청해 알림이 표시되는지 확인. 승인은 대시보드 **예약 관리 → 예약 상태 변경 → 예약 확정**.
4. 다른 기기에서 받으려면 해당 기기에서도 구독. 기기에서 중지하려면 **이 기기 알림 끄기**.

## 서버 운영 설정

- 서버만 사용하는 Vercel Production 환경변수:
  - \`PUSH_VAPID_PUBLIC_KEY\`: EC P-256 VAPID 공개키(base64url, uncompressed 65-byte point)
  - \`PUSH_VAPID_PRIVATE_JWK\`: 같은 키쌍의 비공개 EC JWK(JSON), Vercel 암호화 보관
  - \`MECA_PUSH_WORKER_TOKEN\`: 무작위 32바이트의 hex 문자열, Vercel 서버 비밀 환경변수
  - 선택: \`PUSH_VAPID_SUBJECT\`: 실제 운영 서버의 HTTPS URL 또는 \`mailto:\` 발신자
- DB의 \`meca_private.owner_push_worker_config\`에 worker token의 SHA-256 해시만 등록. 평문은 저장하지 않음. 배포된 Vercel 서버와 DB의 해시가 일치해야 발송 가능.
- 새 예약 생성/고객 변경 API가 저장 직후 즉시 발송을 시도하고, 기존 일일 Cron은 남은 항목을 추가 처리. **Vercel Hobby Cron은 하루 한 번 실행 제한**이 있으므로 실시간 복구 스케줄러가 아님.
- 발송 요청에 대한 푸시 게이트웨이 수락은 실제 기기 화면 표시를 보장하지 않음. 일시적 429/5xx는 최대 3회 처리, 네트워크 결과가 애매하면 중복 방지를 위해 재발송하지 않고 \`uncertain\` 처리.
- GET \`/api/owner-push\`로 설정 가능 여부를 조회하되 VAPID 비밀키·worker token을 절대 공개하지 않음.
- \`owner_push_subscriptions\`은 사용자 JWT와 RLS로 등록·해제, 외부 발송 엔드포인트는 허용된 브라우저 푸시 사업자만 수락.
- 서버는 광범위한 Supabase \`service_role\` 키를 사용하지 않고, 푸시 레코드에만 접근하는 별도 제한 토큰 RPC를 사용.
- 공용 GitHub 저장소에 키 쌍, 비밀 환경변수, 디바이스 구독 정보를 추가하지 말 것.
