# MECA 사장님 예약 이메일 알림: 무료 파일럿 운영 체크리스트

**현재 상태**: 코드와 DB 대기열은 구현됨. 실제 이메일을 전송하려면 발신 서비스 인증을 완료해야 함.

- [ ] Resend 발신 도메인 등록, DNS 인증 완료
- [ ] Vercel Production 서버 전용 설정: `RESEND_API_KEY`
- [ ] Vercel Production 서버 전용 설정: `MECA_OWNER_EMAIL_FROM`
- [ ] Vercel Production 서버 전용 설정: `SUPABASE_SERVICE_ROLE_KEY`
- [ ] Vercel Production 재배포
- [ ] 사장님 계정 이메일 인증 완료 확인
- [ ] 관리자 → 매장 설정 → 사장님 이메일 예약 알림: 발송 가능 표시 확인
- [ ] 테스트용 고객 새 예약 후 메일 수신 확인
- [ ] 테스트용 고객 일정 변경 후 메일 수신 확인
- [ ] 테스트용 고객 예약 취소 후 메일 수신 확인
- [ ] 알림 내역에서 발송업체 접수와 실제 수신 결과 구분
- [ ] Resend 발송량과 개인정보 처리방침·외부 발송 위탁 고지 확인

**제약**: 신규 온라인 예약·고객 일정 변경·취소만 발송. 기존 카카오 알림톡은 별개로 비활성. 발송 서비스가 없는 동안 예약 자체는 계속 정상 접수되며 알림은 대기한다. 보류했던 이벤트를 나중에 무더기로 발송하지 않도록 오래된 알림은 건너뛴다.

**중요**: 이메일 발송 서비스 비밀 키를 이 파일이나 GitHub에 저장하지 않는다. 이 문서는 실제 발송 완료를 뜻하지 않는다.
